# Planner

A Microsoft Project–style planner for Android: tasks and outline, Gantt chart, dependencies (FS/SS/FF/SF with lag), critical path, resources and costs, resource leveling, baselines, earned value, and ClickUp sync.

Same look and setup as Timesheet, Expenses and Medicine.

Every push to `main` builds **Planner.apk** and publishes it under **Releases**.

- Data is stored on the phone (backup/restore in Settings, optional Google Drive backup).
- ClickUp: add your personal API token in Settings, then link a list in the Project tab.
